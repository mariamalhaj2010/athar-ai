أثر AI (Athar AI)

منصة ويب تعليمية بالذكاء الاصطناعي لطلاب المرحلة الثانوية

مشروع تخرج — يُقدَّم لمناقشة أكاديمية أمام لجنة المختصين.

---

1. المشكلة

يحتاج طلاب الثانوية العامة إلى مساعد دراسي متاح في أي وقت، يشرح لهم دروس
المنهاج، يلخّص لهم المواد الطويلة، ويختبرهم بأسئلة تفاعلية بتصحيح فوري —
خارج أوقات المدرسة ودون تكلفة إضافية على الأسرة.

2. الحل المقترح

منصة ويب عربية متعددة المستخدمين، تعمل من المتصفح على أي جهاز، تقدم أربعة
أوضاع: شرح، تلخيص، اختبار تفاعلي، ومحادثة حرة، مدعومة بنماذج لغوية حديثة
عبر وسيط أمني يحمي المفتاح والحصة.

3. معمارية النظام

```
┌─────────────────┐      ┌──────────────────────┐      ┌────────────────┐
│   المتصفح       │      │   الوسيط الأمني        │      │   Google Gemini │
│  (HTML/Tailwind) │─────▶│  Vercel Serverless   │─────▶│    API (مجاني)  │
│  JavaScript RTL  │ POST │  api/ask.js          │      │  سلسلة نماذج    │
│  تخزين محلي      │◀─────│  إخفاء المفتاح +      │◀─────│  احتياطية      │
│  لكل طالب        │ JSON │  تقييد المعدل + تعقيم │      │                │
└─────────────────┘      └──────────────────────┘      └────────────────┘
```

4. التقنيات المستخدمة

الطبقة	التقنية	
الواجهة	HTML5, Tailwind CSS, JavaScript (RTL بالكامل)	
الخلفية	Vercel Serverless Functions (Node.js)	
النموذج اللغوي	Google Gemini API — طبقة مجانية	
التخزين	localStorage (سجل كل طالب على جهازه)	
الاستضافة	Vercel — خطة Hobby المجانية	

5. الجوانب الأمنية (نقطة قوة أمام اللجنة)

1. إخفاء مفتاح API: المفتاح يعيش في متغير بيئة خادم Vercel فقط، ولا
   يصل للمتصفح إطلاقاً — فحتى من يفتح أدوات المطور (F12) لا يراه.
2. منع حقن الأوامر (Prompt Injection): تعليمات النموذج تُبنى في
   الخادم حصرياً، والقيم القادمة من العميل (الوضع/المادة/الصف) تُطابَق
   مع قوائم بيضاء مسموحة فقط.
3. تقييد المعدل (Rate Limiting): حدّ لكل مستخدم (10 طلبات/دقيقة،
   120/يوم) يحمي الحصة المجانية عند استخدام التطبيق من عدة طلاب.
4. خصوصية الطلاب: اسم الطالب وصفه يُحفظان محلياً على جهازه، ولا يُرسل
   للنموذج سوى نص الدرس/السؤال — وهو ضروري لأن الطبقة المجانية تستخدم
   البيانات في تطوير منتجات Google.
5. تعقيم المدخولات: إزالة محارف التحكم، حد أقصى للطول (8000 حرف).
6. حماية XSS: كل نص معروض يمر عبر دالة تهريب HTML قبل إدراجه.

6. المتطلبات والتشغيل

أ. الحصول على مفتاح Gemini (مجاني)
1. افتح https://aistudio.google.com
2. سجّل الدخول بحساب Google → Get API Key
3. خزّنه — ستضعه في الخطوة ج.

ب. رفع الكود على GitHub
1. أنشئ حساباً على github.com ثم مستودعاً جديداً باسم `athar-ai`
2. ارفع الملفين: `index.html` ومجلد `api/` كما هما

ج. النشر على Vercel (مجاني)
1. أنشئ حساباً على vercel.com (يمكن "الدخول عبر GitHub")
2. Add New Project ← استورد مستودع `athar-ai`
3. قبل الضغط على Deploy: Environment Variables ←
   أضف `GEMINI_API_KEY` = المفتاح من الخطوة أ
4. Deploy — خلال دقيقة تحصل على رابط عام `https://athar-ai-xxxx.vercel.app`

7. الحدود الواقعية (صراحة علمية)

- الطبقة المجانية لـ Gemini محدودة بعدد الطلبات/اليوم حسب النموذج؛ عند
  تجاوزها يرد التطبيق برسالة عربية واضحة مع إعادة محاولة تلقائية واحدة.
- تقييد المعدل محفوظ في ذاكرة نسخة الدالة (Stateless nature للدوال
  Serverless) — يكفي للعرض والاستخدام الخفيف، ويُذكر في المناقشة
  كتحسين مستقبلي (نقل العدّاد إلى Upstash Redis مثلاً).
- يتطلب التطبيق اتصالاً بالإنترنت دائماً.

8. التطوير المستقبلي المقترح

- توليد صور توضيحية للدروس داخل وضع الشرح
- لوحة متابعة للمعلم يطلع على نتائج اختبارات طلابه
- تسجيل دخول بالحسابات مع مزامنة السجل عبر الأجهزة
- وضع "مذاكرة سريعة" ببطاقات مراجعة متتابعة
